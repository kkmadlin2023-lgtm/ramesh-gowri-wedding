# Ramesh ♥ Gowri – Wedding Invitation Website 🌸

A stunning, animated digital wedding invitation website for **Ramesh & Gowri**.

## ✨ Features

- 🎊 **Animated Hero** — Floating couple illustration with light beam effects
- 🃏 **Draggable & Flippable Invitation Card** — Drag anywhere, click to flip and reveal details
- 🌸 **Falling Petals Animation** — Continuous canvas-based petal rain
- ⏰ **Live Countdown Timer** — Counts down to November 1, 2026
- 📅 **Animated Calendar** — Highlights the wedding date
- 🎬 **Video Section** — Looping mandala background + drag-and-drop video upload
- 📍 **Google Maps Venue** — Embedded map for Krishnan Thirumana Mandapam, Mettupalayam
- 📸 **Photo Gallery** — Hover-reveal gallery with zoom effects
- 💌 **RSVP Form** — Collects guest info with animated success message
- 🌿 **Watercolor Theme** — Green, cream & maroon palette inspired by the invitation designs
- 📱 **Fully Responsive** — Works on mobile, tablet, and desktop

## 🚀 Getting Started

Simply open `index.html` in any modern browser — no server required!

```bash
# Clone the repo
git clone https://github.com/YOUR_USERNAME/ramesh-gowri-wedding.git
cd ramesh-gowri-wedding
# Open index.html in your browser
```
